# 한계 (limitations) — 실제로 남아 있는 한계만 적는다

1. **의료 공급량 proxy**: 원자료에 병상·의사수가 없어 고유시설 1개 = 공급 1(S1). 종합병원과 의원의 규모 차이를
   반영하지 못한다(종별 가중 S2는 민감도용).
2. **지오코딩 누락**: 의료기관·재가요양기관 일부는 Nominatim으로 좌표를 찾지 못해 공급에서 빠진다(실제 비율은
   `outputs/presentation/01_problem_summary.json`). 공급 과소추정 → 접근성은 상대 비교로 해석한다. 임의 좌표는 만들지 않았다.
3. **수요점 = 행정동 대표점 1개**(동 내 버스정류장 medoid): 동 내부 인구 분포(MAUP)를 반영하지 못한다. 대표점·시설은
   도로망에 스냅하며 스냅 거리를 더한다(최대값은 `accessibility_summary.json`). 폴리곤 중심점 기준과의 순위 상관도 같은 파일에 기록.
4. **보행 네트워크 거리**: 이동 시간·경사·대중교통 배차는 반영하지 않는다. 대중교통 접근성은 정류장 밀도 proxy다
   (GTFS 등 운행정보 미사용).
5. **시 경계 효과**: 성남시 밖 인접 시설(서울 송파·용인 수지 등)은 공급에 포함하지 않는다 → 경계부 동의 접근성 과소추정 가능.
6. **서비스 반경은 직선거리 1.5km**: MCLP 커버 판정은 직선거리다(노선·접근성은 네트워크 거리).
7. **노선 운영값은 가정**: 평균 속도 20km/h, 정차 3분, 최대 순환 90분, 구 보건소 거점. What-if에서 변경 가능하지만
   실제 운영 데이터로 보정하지 않았다. vehicle-km는 1회 순환 기준이며 운행 빈도·비용은 모형 밖이다.
8. **정책 C는 축약 후보 내 정확해**: 계산량 때문에 구별 후보를 8개로 축약한 뒤 조합을 완전탐색한다. 전체 1,301개
   정류장 대상 전역 최적을 보장하지 않으며, 축약 후보가 정책 A의 해를 포함하지 않을 수 있다(현재 데이터에서도 미포함).
   A의 해를 별도 비교해 'C의 운행거리 ≤ A'만 보장한다.
9. **OSM 스냅샷**: 도로망은 다운로드 시점(`data/raw/osm/osm_snapshot_meta.json`) 기준이다.
10. **복지 접근성은 시설이용형 급여만**: 방문형 급여(방문요양·목욕·간호)는 거리 기반 접근성이 성립하지 않아 제외했다.
11. **상관 ≠ 인과**: MVI·hotspot은 우선순위 후보 탐지이며 원인을 입증하지 않는다.
12. **Grounding 검증 범위**: 숫자·지역·정책·지표·표현 규칙을 검사한다. 문장의 미묘한 의미 왜곡까지 모두 잡는다고
    주장하지 않는다. LLM은 선택 계층이며 기본 실행은 결정적 템플릿이다.
13. **Gi\***는 구현하지 않았다. Local Moran's I + 36 시나리오 강건성으로 공간 군집을 판단한다.
14. **경계 데이터**: SGIS 원자료 기반 가공본(vuski/admdongkor, 2026-07-01)이며 공식 배포본이 아니다.
15. **Local Moran 다중검정**: 50개 동 각각 p < 0.05로 판정하며 FDR 등 다중검정 보정은 하지 않았다. 단일 시나리오의
    우연한 유의를 줄이기 위해 36개 시나리오 중 80% 이상 유지되는 동만 '안정 hotspot'으로 본다.
16. **설명 검증의 정책 비교 수치**: 정책 설명에서 라벨 없이 나열한 다른 정책 값은 '입력에 있는 값인지'까지만 확인한다
    (KPI 라벨이 붙으면 해당 정책 값과 대조).
